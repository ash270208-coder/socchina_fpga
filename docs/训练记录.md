## 三、网络与训练配置

```
输入 128×72×3 RGB
conv1 3×3 s1 p1  3→8   +BN+ReLU      conv3 3×3 s2 p1 16→32 +BN+ReLU
conv2 3×3 s2 p1  8→16  +BN+ReLU      conv4 3×3 s1 p1 32→32 +BN+ReLU
head  1×1        32→15（3 锚 × [to tx ty tw th]）→ 18×32 网格
```

| 项 | 值 |
|---|---|
| 锚框 | **k-means 自动估计**：[12.78 8.48]、[16.57 16.08]、[37.10 29.89] |
| 正样本分配 | 最优锚 + 次优锚（对数距离差 ≤0.3 时） |
| ignore 区域 | 锚框与 GT 的 IoU>0.4 但未分配为正样本的格，标 −1 不计损失 |
| 损失 | `yoloLossLayer`：λobj=5 / λnoobj=0.5 / λcoord=5，**按正样本单元数归一化**（不是 numel(Y)） |
| 优化 | SGDM，miniBatch 16，lr0=1e-3，每 15 轮 ×0.5，**80 轮** |
| 回归目标 | tx/ty = 格内偏移（不压缩）；tw/th = log(框/锚)；to = 0/1 |

## 四、踩过的坑（对后续版本重要）

| # | 问题 | 根因 | 修法 |
|---|---|---|---|
| 1 | `trainYOLOv2ObjectDetector` 检测头反向崩溃 | R2024b TransformLayer 的 traced backward 内部报错，错误被吞（GPU/CPU 均复现） | **放弃 yolov2 机制**，改全标准层 + 预编码回归目标 + 自定义损失 |
| 2 | 网络只会输出 0（头范围 ±0.0023） | 正负样本极度不平衡（1728 格 vs ~1.6 正样本） | 加权损失（λobj/λnoobj） |
| 3 | **坐标完全学不动（训练图 IoU = 0.00）** | 损失除以 `numel(Y)`≈13.8 万，坐标只有 ~40 个正样本单元参与 → 梯度被稀释 5 个数量级 | **按正样本单元数归一化**（关键修复） |
| 4 | 得分最高的格是背景格（框画在衣服上） | 背景格坐标未训练 + λnoobj 太弱(0.1) | λ 改为 YOLO 经典配比 + ignore 区域 + 锚框 k-means |
| 5 | `bInt` 尺寸变成 [1 64] | `convB`[1 8] 与 BN 参数[1 1 1 8] 隐式扩展错位成 [1 8 8] | fold_bn 中把 convB 先整形为 [1 1 1 Cout] |
| 6 | stride=2 层 reshape 元素数不符 | `1:stride:allN` 只对一维跳步（列全取） | 用 ndgrid 生成二维窗口起点 |
| 7 | 检测头输出 Inf | 头部 `mOut` 误写为 1（整数累加和没还原实域） | `mOut = sW·sIn` |
