## 一、背景与目标

| 项 | 内容 |
|---|---|
| 原方案 | LBP 级联人脸检测（`LBP评估与替代方案.md`）：尺度覆盖窄、噪声敏感、误检多、**涂颜料人脸检不出** |
| 新目标 | 用**超轻量 CNN**替换 LBP，要求：① 与肤色无关（涂颜料脸可检）；② 一次前向出框（无滑窗扫描）；③ 装得进 PH1P35MDG324 |
| 平台约束 | 器件 PH1P35MDG324；像素钟 74.25 MHz；检测器可用资源（撤掉 LBP 后）≈74 块 ERAM(185 KB) / 15 DSP / ~10K LUT |
| 分工 | **PC（MATLAB）负责训练 + 量化翻译；FPGA 只做前向推理**（CNN 训练需要浮点/梯度，FPGA 既不适合也无需承担） |

## 二、总体方案

```
PC / MATLAB（本子项目）                          FPGA / Verilog（下一步）
─────────────────────────────                   ────────────────────────────
WIDER FACE 数据 → 训练小 CNN                     从 ROM 读 int8 权重（.mem）
            ↓ 量化 + 导出 .mem                   卷积引擎（行缓存 + MAC 阵列）
       浮点↔定点验收 IoU 0.971          →        逐层算完 → 解码人脸框
                                                 → OSD 画框 + 形心 → 云台 PID
```

**网络**（按 FPGA 预算倒推设计）：

```
输入 128×72×3 RGB（720p ÷10）
conv1 3×3 s1 p1  3→8   +BN+ReLU     → 128×72×8
conv2 3×3 s2 p1  8→16  +BN+ReLU     →  64×36×16
conv3 3×3 s2 p1 16→32  +BN+ReLU     →  32×18×32
conv4 3×3 s1 p1 32→32  +BN+ReLU     →  32×18×32
head  1×1       32→15（3 锚 × [to tx ty tw th]）→ 18×32×15
```

- 参数量 **1.55 万**（int8 权重约 16 KB）；算力 **12.9 M MAC/帧**；
- 15 DSP 下 11.6 ms @100% 利用率 → **60 fps 可行**（70% 效率贴满一帧，兜底 30 fps）；
- 覆盖距离（人脸宽 15 cm、HFOV 60°）≈ **0.2~1.5 m**。

## 三、PC 端（MATLAB）做了什么

| 步骤 | 内容 | 关键决策 / 理由 |
|---|---|---|
| ① 数据准备 | 解析 WIDER FACE 原始标注（无 `#` 前缀格式），读 6572 张 → 质量过滤后取 **3000 张 / 4746 个框** | 过滤规则：脸宽/图宽 ∈[8%,60%]、丢弃严重模糊/invalid/夸张姿态/重度遮挡；**光照极端保留**（本机摄像头画面偏暗，暗光样本有用） |
| ② 网络设计 | 4 层卷积 + 1×1 检测头，输出 18×32×3 锚 × [to tx ty tw th] | 尺寸、通道数是按 ERAM/DSP 预算反推的；1×1 头避免额外算力 |
| ③ 训练 | SGDM、miniBatch 16、lr 1e-3（每 15 轮 ×0.5）、**80 轮**（GPU 约 2 小时） | 锚框由数据 **k-means 自动估计**；每 GT 分配最优+次优锚；引入 **ignore 区域**；加权损失 λobj=5 / λnoobj=0.5 / λcoord=5 |
| ④ 量化导出 | BN 折叠进卷积 → 逐层 int8 对称量化 → 激活校准 → 导出 `.mem` + 参数契约 | 硬件没有 BN 层；权重/int32 偏置/LUT 全部文本化，`$readmemh` 直接读 |
| ⑤ 验收 | PC 上按 FPGA 的整数算法重算，与浮点对比 | **首框 IoU = 0.971** → 量化链路正确，可以上板 |

**训练质量指标**：训练集定位 IoU 中位 0.37（修复归一化前为 0.00）；测试图 top-1 分数 0.689（全格分数中位 0.000，区分度良好）。

## 五、踩过的坑（浓缩版，详细见 `训练记录.md`）

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | `trainYOLOv2ObjectDetector` 检测头反向崩溃 | R2024b TransformLayer 的 traced backward 内部报错且错误被吞（GPU/CPU 均复现） | 放弃 yolov2 机制，改**全标准层 + 预编码回归目标 + 自定义损失层** |
| 2 | 网络只会输出 0 | 正负样本极度不平衡（1728 格 vs ~1.6 正样本） | 加权损失 |
| 3 | **训练图 IoU = 0.00（坐标学不动）** | 损失除以 `numel(Y)`≈13.8 万，坐标仅 ~40 个正样本单元参与 → 梯度被稀释 5 个数量级 | **按正样本单元数归一化**（决定性修复） |
| 4 | 框画在衣服上 | 背景格坐标未训练 + λnoobj 过弱 | λ 改经典配比 + ignore 区域 + k-means 锚框 |
| 5 | `bInt` 尺寸变 `[1 64]` | `convB`[1 8] 与 BN 参数[1 1 1 8] 隐式扩展错位 | fold_bn 中先整形 `[1 1 1 Cout]` |
| 6 | stride=2 层 reshape 元素数不符 | `1:stride:allN` 只在一维跳步 | ndgrid 生成二维窗口起点 |
| 7 | 检测头输出 `Inf` | 头部 `mOut` 误写为 1（整数累加和未还原实域） | `mOut = sW·sIn` |

## 六、与 FPGA 端的分工与下一步

**FPGA 端要做的（`CNN学习与准备路线.md` 阶段 2~4）**：

```
① 行缓存 + 3×3 滑窗 + 权重 ROM → 先打通 conv1，与 x1_conv1.txt 逐位对齐
② 参数化 Cin/Cout/stride/pad/K → 依次打通 conv2/3/4
③ 定点乘移位（mOut_q16）+ clamp → 逐层对齐
④ head_conv(1×1) + 解码（exp LUT / 锚框 / clamp / 最高分单框）→ 与 boxes.txt 对齐
⑤ 接入视频通路：÷10 降采样（新增）→ 检测 → 复用 9.16 时域确认 → OSD 画框 → 形心 → PID
```

**资源规划（契约文档第五节）**：bufA（x1, 29 块）→ 复用为 x3/head；bufB（x2, 15 块）→ 复用为 x4；权重 7 块；输入帧 RGB565 双缓冲 16 块；**合计 ≈67 ≤ 74 块 ERAM**。

**后续可选优化**：
1. **补彩绘脸数据**（核心需求）：拍 50~100 张涂颜料的脸 → `mode='AB'` 重训；
2. 继续加轮数（IoU 0.37 → 0.5+）；
3. 分数阈值 0.15 上板后按误检情况调整（0.15~0.3）。

## 七、如何复现

```
（MATLAB，工作目录 matlab/cnn_detector）
step0_check_env        环境自检（R2024b + 4 个工具箱）
step1_prepare_data     组装数据表（mode='B'，WIDER 路径在脚本里）

step3_quantize_export  量化导出 → out/*.mem + params_summary.txt
step4_golden_forward   验收 IoU + 导出 out/golden/ 逐层金标准
step5_diagnose         （可选）top 候选 + 训练图定位质量
```

## 八、结论

- **可行且已落地**：之前的"轻量 CNN 不可行"结论基于"只能在剩余资源里塞"的错误前提；
  撤掉 LBP 释放 60 块 ERAM 后，1.55 万参数的 int8 检测器完全装得下（占 67/74 块，算力 60 fps 可行）；
- **PC 端全部完工**：数据→训练→量化→验收闭环，浮点↔定点 IoU 0.971；
- **可交付**：一份可直接写进 Verilog 的权重 + 契约 + 金标准，FPGA 端只剩"照着做"。
