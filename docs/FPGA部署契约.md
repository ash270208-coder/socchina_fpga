# FPGA 部署契约（方案 A · int8 小检测器）

> 本文是 PC 端（`matlab/cnn_detector/`）与 FPGA 端（Verilog）之间的**接口契约**，
> 所有数值取自实际训练结果的 `out/params_summary.txt`，Verilog 照本文实现即可。
> PC 端验证状态：浮点↔定点 IoU **0.971**（量化链路正确）。

---

## 一、网络结构与各层参数

输入：**128×72×3 RGB**，uint8，0..255（scale = 1）

| 层 | 类型 | K | stride | pad | 尺寸 | sW | sIn | sOut | mOut | MAC/帧 |
|---|---|---|---|---|---|---|---|---|---|---|
| conv1 | 3×3 | 3 | 1 | 1 | 3→8 | 1.52428e-4 | 1 | 0.0420385 | 0.00362591 | 1,990,656 |
| conv2 | 3×3 | 3 | 2 | 1 | 8→16 | 7.11058e-3 | 0.0420385 | 0.0228191 | 0.0130995 | 2,654,208 |
| conv3 | 3×3 | 3 | 2 | 1 | 16→32 | 5.57427e-3 | 0.0228191 | 0.0210655 | 0.0060383 | 2,654,208 |
| conv4 | 3×3 | 3 | 1 | 1 | 32→32 | 1.88137e-3 | 0.0210655 | 0.00945782 | 0.0041904 | 5,308,416 |
| head_conv | 1×1 | 1 | 1 | 0 | 32→15 | 9.39662e-3 | 0.00945782 | — | 8.88716e-5 | 276,480 |
| **合计** | | | | | | | | | | **≈12.9 M MAC/帧** |

各层特征图（int8）：
```
x1: 128×72×8   = 73,728 B      x3: 32×18×32 = 18,432 B
x2:  64×36×16  = 36,864 B      x4: 32×18×32 = 18,432 B
head 输出（实数域，建议 int16/Q12 存储）: 32×18×15 → 17,280 B（int16）
输入帧（RGB，建议存 RGB565 省存储）: 128×72×2 = 18,432 B
```

## 二、定点计算（Verilog 必须照抄）

```
acc     = Σ(Wq·xq) + b_int          Wq=int8(-128..127), xq=uint8(0..255), b_int=int32
xq_next = clamp(round(acc · mOut), 0, 255)          // conv1..conv4（ReLU 已含在 clamp 下界）
head    = acc · (sW·sIn)            // head_conv：还原实数域，送解码（mOut = sW·sIn = 8.88716e-5）
```

**硬件实现建议**：
- 累加器宽度：每层 `|acc|` 最大约 `127×255×(K²·Cin)` + `|b_int|`，取 **28 bit 有符号**（48-bit DSP 累加器余量充足）；
- `mOut` 用定点常数乘：如 `mOut_q16 = round(mOut × 2^16)`（conv1=238、conv2=858、conv3=396、conv4=275），
  硬件 `xq_next = (acc × mOut_q16) >>> 16`，一次 DSP 乘法即可；
- `head` 同法：`head_q12 = (acc × round(8.88716e-5 × 2^12)) >>> 12`，输出 Q12 定点送解码。

## 三、检测头解码（每锚 5 通道，顺序 `[to tx ty tw th]`）

**锚框（k-means 自动估计，输入像素单位）**：

| 锚 | w | h | 定点建议（Q4） |
|---|---|---|---|
| 1 | 12.7754 | 8.4810 | w=204, h=136 |
| 2 | 16.5736 | 16.0840 | w=265, h=257 |
| 3 | 37.1017 | 29.8886 | w=594, h=478 |

**解码流程**：
```
score = clamp(to, 0, 1)                       // 回归训练直接输出 0/1，原始值即分数
tx = clamp(tx, 0, 1), ty = clamp(ty, 0, 1)    // 格内偏移（不是 sigmoid！）
w  = anchorW · exp(tw)                        // exp 用 lut_exp.mem
h  = anchorH · exp(th)
cx = (gx + tx) · 4,  cy = (gy + ty) · 4       // 格宽 = 128/32 = 4；格高 = 72/18 = 4
框 = [cx - w/2, cy - h/2, w, h]
```
- 网格：18×32（两次 stride-2 下采样），共 576 格 × 3 锚 = **1728 个候选框/帧**；
- 后处理：`score ≥ 0.15` → 取**全局最高分 1 框** → 板级叠加 9.16 的时域确认 → OSD 画框；形心送 PID。

**exp LUT**（`lut_exp.mem`）：1024 项 ×16bit Q11，输入 `x ∈ [-4,4)`，`idx = round((x+4)×128)`，
输出 `e^x`（Q11，即 `值/2048`）。检测头实域范围实测 ±1.54，远在 LUT 范围内 ✓

## 四、权重的 `.mem` 文件

| 文件 | 内容 | 格式 |
|---|---|---|
| `w_conv1..4.mem`、`w_head.mem` | int8 权重 | 每行 1 个值（2 位 hex 补码），顺序 = **列主序 [ky kx cin cout]** |
| `b_conv1..4.mem`、`b_head.mem` | int32 折叠偏置 | 每行 1 个值（8 位 hex 补码），顺序 [cout] |
| `lut_exp.mem` | 1024 项 Q11 | 每行 1 个值（4 位 hex），输入 x∈[-4,4) |

BN 已折叠进卷积（硬件无 BN 层）✓

## 五、资源预算（PH1P35，撤掉 LBP 后可用 ≈74 块 ERAM / 15 DSP / ~10K LUT）

- **算力**：12.9 M MAC / 15 DSP = 0.86 M 拍 = **11.6 ms @74.25MHz（100% 利用率）→ 60fps 可行**；
  按 70% 效率 ≈ 16.6 ms（贴满一帧）→ 兜底：降输入到 128×64 或检测跑 30fps；
- **特征图缓冲复用方案**（省 ERAM）：
  - bufA：x1（29 块）= 之后复用为 x3 / head 输出；
  - bufB：x2（15 块）= 之后复用为 x4；
  - 权重约 16 KB（7 块）；输入帧 RGB565 双缓冲（2×8=16 块）；
  - 合计 ≈ **67 块 ≤ 74** ✓（紧，需按此规划，不要给每层独立缓冲）
- **降采样器**：现有 ÷6 要换成 **÷10**（1280/10=128、720/10=72，正好 16:9）；建议 10×10 块平均（同时抗混叠）。

## 六、ModelSim 金标准流程

1. 跑 `step4_golden_forward`（已加导出开关），会在 `out/golden/` 生成：
   - `x0_input.txt`：输入 RGB（128×72×3）
   - `x1_conv1.txt` … `x4_conv4.txt`：各层量化后激活（0..255）
   - `head_real.txt`：检测头输出（Q12 定点整数）
   - `boxes.txt`：浮点/定点最终框 + 分数
   每个文件第 1 行是尺寸，之后每行一个值（列主序）。
2. Verilog 测试平台读 `x0_input.txt` 喂进卷积引擎，把每层输出与 `xN_*.txt` **逐位比对**；
3. 全部一致后再接视频通路。

## 七、施工顺序（对应 `CNN学习与准备路线.md` 阶段 2~4）

```
① 行缓存 + 3×3 滑窗 + 权重 ROM 读取（先做单层 conv1，与 x1_conv1.txt 对齐）
② 参数化：Cin/Cout/stride/pad/K → 依次打通 conv2/conv3/conv4
③ 定点乘移位（mOut_q16）+ clamp → 逐层输出对齐
④ head_conv（1×1）+ 解码（exp LUT / 锚框 / clamp / 最高分单框）→ 与 boxes.txt 对齐
⑤ 接入视频通路：÷10 降采样 → 检测 → 时域确认 → OSD 画框 → 形心 → PID
```
